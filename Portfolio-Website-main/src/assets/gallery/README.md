# Photography galleries

Add your photos to the matching category folder. Supported formats are AVIF,
JPG/JPEG, PNG, and WebP. The filename is used as the image's accessible alt
text, so use descriptive names such as `outdoor-family-portrait.jpg`.
For faster loading, resize photos to a maximum 1600-pixel longest edge and
compress them before adding them to a gallery.

- `portraits/`
- `studio/`
- `birthdays/`
- `events/`
- `weddings/`
- `graduations/`

When a category folder contains photos, they appear in place of that category's
sample gallery. If the folder is empty, the sample photos remain visible.
